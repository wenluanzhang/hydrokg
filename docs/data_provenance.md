# Data provenance

HydroKG uses a frozen curated dataset containing 159 hydrovoltaic device records
and 52 fields. Each row represents one experimental device record derived from
the literature. The release does not broaden that corpus or infer additional
records.

Fields include bibliographic provenance, normalized material and structure
descriptors, ionic and electrolyte context, electrode configuration,
experimental conditions, performance values, and curator-harmonized
interpretive labels. The supplied metadata distinguishes directly reported,
curator-normalized, and analyst-derived fields where applicable.

Record-level source DOI provenance is retained where available. The repository
does not redistribute source articles or article PDFs. Rights in the source
publications remain with their respective authors and publishers, and access to
those publications remains subject to publisher terms.

Missing source reporting is retained as unavailable information. A missing
value does not mean that a property, condition, or physical contribution was
experimentally absent.

The repository's MIT license applies to repository code. No separate license
for the curated dataset is asserted during this release preparation, and the
MIT license does not relicense publisher-owned material.
